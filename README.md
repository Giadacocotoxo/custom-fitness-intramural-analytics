# Custom Fitness & Intramural Analytics Dashboard
**Developer:** Jaden Juliun D'Souza

## Project Overview
This project is an independent data architecture engineered to monitor personal weightlifting progression, nutritional macro-metrics, and caloric intake baselines. By combining business management logic with data tracking frameworks, it transforms raw biometric inputs into actionable performance trends.

## Technical Architecture & Excel Logic Used
* **Data Automation:** Engineered a multi-tab interconnected architecture to log workout volume, macronutrients, and weight variations.
* **Nested Logical Formulas:** Programmed conditional formatting and `IF` logic to dynamically flag daily caloric deficits and highlight missed protein targets.
* **Statistical Visualization:** Integrated dynamic line charts utilizing `AVERAGE` functions to visually map training consistency and calculate estimated one-rep max (1RM) strength trends.

## Future Scale
Planned integration with Python data structures to automate raw biometric data ingestion via web-scraped fitness APIs.
